# Что делать дальше — по порядку

Я подготовил стартовый проект. Твоя часть — только открыть, быстро проверить и загрузить.

## 1. Скачать и открыть

**Важно:** Xcode работает на macOS. Если у тебя сейчас только Windows-компьютер, проект и репозиторий можно подготовить, но для запуска и проверки приложения понадобится Mac (свой, учебный или доступный удалённо).

1. Скачай архив `LittleLemonCapstone.zip` и распакуй его.
2. На Mac открой файл `LittleLemonCapstone.xcodeproj` в Xcode.
3. Вверху выбери симулятор iPhone и нажми ▶ **Run**.

## 2. Быстро проверить требования

1. При первом запуске появятся три страницы Onboarding. На второй странице введи имя и email, на третьей — номер телефона (необязательно).
2. На главном экране проверь блоки Header, Hero, Menu Breakdown и Food Menu List.
3. Нажми строку Search и попробуй найти `Greek`.
4. Нажми категории Starters / Mains / Desserts — список должен фильтроваться.
5. Открой Profile, измени имя, нажми Save changes.
6. Останови и снова запусти приложение. Убедись, что изменение осталось.
7. Нажми Log Out и подтверди действие. Должен открыться Onboarding, старые данные не должны подставиться.

## 3. Добавить макет через Figma

1. Открой Figma и создай новый Design file.
2. Перетащи в окно файл `Design/MainScreenWireframe.svg`.
3. Выдели макет → справа **Export** → JPG → Export.
4. Добавь полученный JPG в папку `Design` проекта и сохрани изменения.

В архиве уже лежит JPG-превью. Но для буквального выполнения требования Coursera лучше импортировать SVG в Figma и экспортировать JPG из Figma.

## 4. Загрузить в GitHub

1. На GitHub создай новый пустой репозиторий.
2. Открой Terminal в распакованной папке проекта.
3. Выполни команды, подставив адрес своего репозитория:

```bash
git init
git add .
git commit -m "Add Little Lemon iOS capstone app"
git branch -M main
git remote add origin https://github.com/ТВОЙ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

4. Скопируй ссылку на GitHub-репозиторий.
5. На Coursera открой **My Submission / Моя подача**, название укажи `iOS Developer Capstone Project`, вставь ссылку на GitHub и отправь.

## 5. Оценить двух однокурсников

В файле `PEER_REVIEW_TEMPLATE.md` есть таблица по всем критериям из задания. Заполняй её отдельно для каждого из двух проектов, отмечая только то, что реально проверила.
